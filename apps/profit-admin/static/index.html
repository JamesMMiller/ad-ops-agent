Unit economics (ACTIVE SKUs)

ACTIVE catalog SKUs (not only what sold). Landed = unitCost + postage. Contrib = sell − landed − fee estimate. Margin = contrib ÷ sell. Min ROAS = sell ÷ contrib (ads must return at least this multiple of spend to cover the unit). Max CPA = contrib (highest cost-per-purchase that still leaves £0 unit contribution).
